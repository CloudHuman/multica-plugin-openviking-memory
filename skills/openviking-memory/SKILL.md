# OpenViking 记忆使用规范（Multica）

你在 Multica 上执行任务，配备 OpenViking 记忆系统。记忆按范围隔离：你能读到**当前这次运行所属的协作记忆**（issue 任务的协作记忆 / 与该成员的私聊记忆 / 该自动化的记忆）、**你自己的公共记忆**、把工作交给你的**委派通道**、以及**工作区共享记忆**；你主动记录的内容进入**你的公共记忆**（跨任务可见），运行结束后的自动归档进入这次运行所属的协作记忆。其他智能体的私有内容、他人的私聊记忆对你不可见——这是设计使然，不要尝试绕过。

## 什么时候做什么

### 1. 任务开始时：先召回

接到任务、看到新评论或交接说明后，第一步调用 `memory-recall` 工具：

- `query` 用任务目标或新要求原文（自然语言即可，不要只给关键词）。
- 召回会自动覆盖**你当前这次运行**所属的协作记忆，通常不需要 `issue_id`。结果里的 `run.bound: true` 表示召回已绑定到当前运行，此时点名别的 issue 会被忽略（`notes` 里会说明）——这是隔离，不是故障。
- `run.bound: false` 表示当前 multica 没有告诉插件是哪次运行在调用：这时如果你在处理某个 issue，带上它的 ID 或编号（如 `MUL-123`）作为 `issue_id`，才能命中该任务的协作记忆。
- 拿到条目后**先读来源再引用**：条目里的 `uri` 是原始文件，`scope` 说明它来自哪个范围。召回内容是**参考证据**，不是结论本身。

判断标准：

- 问题涉及"之前怎么定的 / 有什么约定 / 上次用了什么方案 / 谁负责过什么"→ 必须先召回。
- 明显的一次性新需求 → 可以不召回，直接执行。

### 2. 执行中：诚实对待记忆

- **当前请求优先**。用户本次的明确要求和实际执行结果，优先于任何记忆。冲突时以当前为准，并可在回复中指出记忆已过时。
- **没有就是没有**。召回结果为空、或没有相关条目时，直接说"没有相关记忆"，**不要编造"记得"的内容**。
- **记忆服务不可用时继续干活**。工具报错就如实说明并按无记忆情况完成任务，不要因此中断交付。
- 收到追加要求或新评论时，**按新内容再召回一次**（新问题可能对应不同的旧记忆）。

### 3. 值得沉淀时：主动记录

用 `memory-remember` 把**可复用的结论**写进你的公共记忆。判断标准——将来另一个任务里的你会想问的问题：

- 业务/技术约定：命名规范、分支策略、"某场景必须先做 X"。
- 关键决策及其理由：为什么选 A 不选 B，当时的约束是什么。
- 踩坑教训：某个配置的坑、某个接口的行为陷阱、验证过的修复方法。
- 对协作方的工作偏好（有证据时）。

**不要记录**：任务过程的流水账、一次性的临时信息、含密钥/内网地址等敏感内容、未经你验证的猜测、私聊里成员告诉你的私人内容。可复用类别（experiences / cases / preferences / entities）的公共记忆可能被**晋升进工作区共享记忆**，工作区里所有智能体都会读到。

写法要求：一条记忆一个主题；自包含（不依赖"本次任务"上下文也能读懂）；给出适用条件。`kind` 按性质选：experiences（经验教训）/ cases（案例做法）/ entities（关键对象事实）/ preferences（偏好约定）/ events（重要里程碑）。

### 4. 收尾时：确认状态（需要时）

想确认本次运行是否已被归档并抽取为长期记忆，调用 `memory-status`。注意：**归档成功、抽取完成、产生可用记忆是三件事**，工具会分别展示：归档后抽取为 `pending`，之后是 `done`（已抽取）、`redriven`（抽取失败，已在新会话重试）、`failed` 或 `timeout`。抽取失败由服务自动重试，你不需要重复记录同一内容。

## 原生 OpenViking 工具（ov-*）

`ov-search` / `ov-read` / `ov-write` 等是 OpenViking 的原生工具，**只作用于你自己的记忆空间**：URI 写成 `viking://~/…`（不写时默认就在这里）。`viking://resources`、`viking://agent` 等账号共享的命名空间和其他智能体的空间会被直接拒绝（`outside_own_space`）。要读任务协作、私聊或共享记忆，用 `memory-recall`。

## 边界与信任

- 记忆带作者与来源标记，用于追溯；**相互矛盾的记忆需要核实**，不能默认新的一定对。
- 你看到的共享记忆来自整个工作区；你记录的公共记忆只属于你。写入即被视为你确认过的内容。
- 不要把他人私聊内容或你无权访问的范围当作"共享记忆"引用。
